# 簡体字 (zh-Hans) 画面の文字: 訳した人のメモ

対象: `src/game/i18n/zhHans/<名前空間>.ts` の 1,912 キー (16 ファイル)。日本語の原文から AI が訳した。**ネイティブの確認はまだ**。繁體字は触っていない (簡体字から `node tools/i18n/zh-hant.mjs` で作る)。

## 用語集 (docs/I18N.md 5 章) と違う、または用語集に無くて決めた語

- **デッキ → `队伍`** (用語集に無い)。画面名の編成 `编队` と分けるため。`队伍1` `队伍名称` `队伍最多N个`。
- **名鑑 (ホームの下の菱形ボタン・文中の「名鑑で編成」「名鑑へ」) → `编队`**。理由: 用語集は 名鑑 = 图鉴 だが、ホームの菱形ボタンの絵には「編成」と描いてあり (`roster_normal.png`)、飛び先の画面の題も「キャラ編成」(`英雄编队`)。画面の名前を統一するため、`home.roster` と「名鑑へ」「名鑑で編成しますか？」は `编队` / `前往编队` / `前往编队界面` にした。**本物の図鑑 (`hero.collection.*`) と「ガチャで持っているキャラも名鑑に増えます」は `图鉴`** のまま。
- **助っ人 → `助手`** (用語集どおり)。校正者へ: 中国のゲームでは **`助战`** (助战角色) が普通。`助手` だと「アシスタント」に読めるかもしれない。変えるなら、画面 (`hero.helper.*` `alliance.helper.*` `alliance.raid.*` ほか) と、データ表の台詞・スキルの説明を、そろえて直す。
- **同盟長 → `盟主`、幹部 (原文は「副長」とも) → `副盟主`**。猟師ギルド長 (ストーリー) の `公会长` と混ざらないように。
- **同盟対抗戦 → `同盟战`**、リーグ名 → 青铜 / 白银 / 黄金 / 铂金 / 钻石、共闘ボス → `共斗首领`、寄付 → `捐献`、紋章 → `徽章`、同盟ポイント・対抗戦のポイント → `积分`、救援 → `求援`/`援助`。
- **同盟ミッション → `同盟任务`** (ミッション = 任务)。
- **引き継ぎ (データ・コード) → `数据迁移` / `迁移码`**。ほかの案: `引继码` (日本のゲームの中国語版でよく見る言い方)。設定の「発行」は `生成`。
- **メール・X のアカウントの 登録 / 解除 → `绑定` / `解绑`** (`common.register` `common.release` もこの意味)。未登録・未連携 → `未绑定`。
- **プレイヤー名 → `昵称`**。アカウント → `账号`。
- **職業 (`sys.class.*`)**: 戦士 `战士`、魔術師 `法师` (`魔术师` は手品師の意味になる)、弓兵 `弓箭手`、守護者 `守护者`、術師 (回復役) `治疗师`。装備の部位 (`sys.slot.*`): 武器 `武器`、防具 `护甲`、装飾 `饰品`。
- **曜日**: 短い形 (`quest.weekday.short.*`、ステージ名・一覧に出る) は `周一`〜`周日`、長い形は `星期一`〜`星期日`。ホームのログインボーナスのカレンダーの見出し (`home.weekday.*`) は 1 字 `日 一 二 三 四 五 六`。
- **キャンペーン (倍率ブースト) → `加成活动`**。**パス限定 → `通行证专属`**。**お気に入り → `特别关注`**。メッセージの「全体」タブ → `世界`。
- **排出率 → `召唤概率`**、ピックアップ → `概率UP`、天井 → `保底`、10連 → `10连` (数字を残す。検査が数字の一致を見るので `十连` にしない)。
- **狂獣 → `狂兽`**、**ウロボロス → `乌洛波洛斯`** (`quest.stageName.finalBoss` `finalWave`)。**データ表 (`worldZhHans.ts`) の敵・ボスの名前と、そろえてほしい** (相棒の担当。`狂兽` はストーリーの訳とも同じ)。
- **軍団 (フレンドのグループチャット) → `军团`**。軍団長 (主人公) の `军团长` と同じ字だが、別のもの。
- **建築員 → `建造员`、売上 → `收益`、城 → `城堡`、撤去 → `移除`、解体 → `拆除`、再建築 → `重建`、移転 → `搬迁`** (村)。撤去と解体で、`拆除` が 2 つの意味にならないよう、撤去だけ `移除` にした。
- **「OK」→ `OK` のまま** (`common.ok`、`hero.roster.newDeckHint` ほかの「OK を押して」)。`ui/Dialogs.ts` の入力ダイアログのボタンが、翻訳を通さず `'OK'` と直書きされているため。

## 校正者へ (自信が無い所・見てほしい所)

- **法律の名前**: `shop.legal.commerce` = `《特定商业交易法》相关标示`、`shop.legal.funds` = `《资金结算法》相关标示`。日本の法律 (特定商取引法・資金決済法) の呼び方。法務の確認が要る。
- **通貨**: 商品の値段は日本円 (`¥1,500`)。文中の「約3,000円ぶん」は `约合3,000日元` と書いた。中国の利用者に `¥` は人民元に見えるので、そのまま出してよいか、運営に確認。
- **短い札の長さ**: 戦闘の状態表示 (`battle.status.*` `quest.infiniteMode.*`、`攻防提升` `攻防下降` 4 字)、`通行证专属` (5 字)、`还有 …后` の形のボタン (`home.supplyModal.in` = `{formatDuration}后`、時間が長いと幅を超えるかもしれない) は、画面で全部は確かめていない。
- **`剩余` と `还剩 / 还需`**: 残り時間は 画面ごとに `剩余N天` (システム表記) と `还剩N小时` (同盟) が混ざる。同盟の画面は原文が「あと」で始まる文なので、`还剩` にした。
- **口調**: 画面の説明は主語を省いた。ルリ (チュートリアル) だけ `哦` `啦` `吧` をつけた (`琉璃：加油建设村庄哦！`)。`来自琉璃` は `琉璃：` に縮めた。
- **無限モードの「撃破数」**: 数に助数詞をつけなかった (`击败 12`)。
- **「ガチャ詳細」「召喚」**: `召唤` / `召唤详情`。ボタンが狭いとき `抽卡` に替えてよい、と用語集にあるが、替えていない。
- **台湾向けの変換で気になるもの** (繁體字の校正の目安): `视频` (`语音与视频`、`动画`) → 影片、`邮箱` → 信箱 (OpenCC がどうするか、生成後に見てほしい)、`昵称` → 暱稱、`登录` → 登入、`点击` → 點選 (台湾は `點選` も使う)、`眩晕` → 暈眩 (OpenCC は 眩暈)、`迁移` → 遷移、`服务器` → 伺服器、`渠道` は使っていない。
