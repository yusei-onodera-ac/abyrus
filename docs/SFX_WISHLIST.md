# 効果音の欲しいもの一覧

効果音は、あなたが用意する担当です（BGM・ジングルと、キャラとルリの声は、生成済み）。
このリストは、**ゲームに欲しい音を、鳴る場面ごとにまとめたもの**です。全部そろえなくても動きます。
音のファイルがない間は、いまの「ピ・ポ」という簡単な合成音（コードが作る音）が鳴ります。

## 置き方（ルール）

- 置き場所: `public/assets/audio/se/<名前>.mp3`（`.ogg` でも可。名前は下の表の「名前」）
- 形式: mp3、モノラルでよい、44.1kHz。**先頭に無音を入れない**（押した瞬間に鳴らしたい）。
- 音量: ピークを -3dB くらいにそろえる（設定画面の「効果音」の音量で、ゲームが下げます）。
- 長さ: 目安は「長さ」の列。短い音（0.3秒以下）は、連続で鳴る（戦闘中）ので、特に短く、耳に痛くないものに。
- 同じ音が連続で鳴る場面（攻撃・ボタン）は、**2〜3種類**あると飽きません。`hit_1`, `hit_2`, `hit_3` のように、番号を付けてください。
- 「配線」の列: **済** = コードがその場面で鳴らす準備ができている（`SFX_FILES` に名前を足すだけで鳴る）。
  **未** = ファイルを渡してもらえれば、私がその場面に鳴らすコードを足します（いまは無音）。

## 優先順位のおすすめ

1. **1の表（戦闘とボタン）** — いちばん耳にする音。ここが決まると、ゲームの手触りが変わります。
2. **`reveal6`** と、3のガチャの音 — ★6は、このゲームで一番盛り上げたい瞬間です。
3. **`coin_get`・`reward_open`・`error`** — 毎日何度も受け取る・失敗する場面です。
4. 村・強化・同盟の音 — 遊び込んだ人が気づく音です。

## ファイルを置いたあと

- `tap` `hit` `crit` `skill` `heal` `boom` の6つ: **すでにコードに登録済み**なので、`public/assets/audio/se/` に同じ名前で置くだけで鳴ります
  （ファイルがない間は、合成音が鳴ります）。
- `confirm` `reveal` など、**配線が「済」でも、ファイルの登録がまだ**のもの: 名前をそのまま置いてもらえれば、
  `src/game/systems/SoundSystem.ts` の `SFX_FILES` に1行足します（私が足します）。
- `hit_1` 〜 `hit_3` のような、複数の音をランダムに鳴らすもの: 私がコードを直します。
- **未** の音: ファイルと名前を渡してください。鳴らす場面のコードを、私が足します。
- 渡す方法: フォルダに置いて「置いた」と言ってもらえれば、あとはこちらで配線・確認・デプロイします。
