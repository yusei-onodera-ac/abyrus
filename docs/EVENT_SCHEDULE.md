## 2. 期間限定イベント

イベントは2種類です。どちらも、**イベント通貨**を集めて、**累計報酬**（集めた数に応じて、自動で解放）と**交換所**（通貨で好きなものと交換）に使います。

- **イベントダンジョン型**: 曜日ダンジョンと同じ4段階（初級・中級・上級・超級。開放条件・強さ・スタミナも同じ）。クリアするたびに、スタミナ×2 のイベント通貨がもらえる（初級20、中級28、上級36、超級60）。初回クリアで魔晶石。クリア済みの段階は掃討できる。敵の姿と背景は、イベントごとに決めた地域のもの。ゴールドは通常の2倍。
- **ミッション型**: ダンジョンなし。いつもの冒険（クエスト、ガチャ、強化、遠征、村、補給）のミッションで、通貨がたまる。すべて終えると、ちょうど最後の累計報酬に届く。

どちらにも、「ログインした日」のミッションがあります。ホームを開くか、何かを遊ぶと、その日が数えられます。
期間が終わっても、**交換所と累計報酬の受け取りは、3日間（夏は4日間）だけ**できます。ダンジョンとミッションの進行は、終了と同時に止まります。通貨は、交換期間が終わると使えなくなります。

## 6. 運営のしかた

**予定を変える**: `src/game/data/schedule.ts` を直す（日付は "MM-DD"、年は自動）。イベントは `makeEvent({...})`、ガチャは `pickupGacha({...})`、キャンペーンは `campaign(...)` の1行です。
その後、`npm test`（日付の穴・重なり・確率の合計・ピックアップが実在するか、などを調べます）と、`npm run schedule:doc`（このファイルを書き直す）を実行します。

**絵**: イベントは `public/assets/events/<id>.jpg`（1050×450）、ガチャは `public/assets/gacha/<id>.jpg`（1024×576）。無いときは、色つきの仮のバナーが出ます。
作り直すときは、`tools/art/manifest.mjs`（`limited` と `pickups` のグループ）を直して、`node tools/art/generate.mjs --group limited,pickups --force --only <id>`、`python tools/art/process.py --install --group limited,pickups` です。

**別の日の画面を見る**（開発用）: アドレスに `?date=2027-01-05` を足すと、ゲームの時計がその日（と時刻）から動きます。`?scene=Event&date=2027-03-20`、`?scene=Schedule&date=2027-06-01` のように使います。`?battle=0&mode=event&event=launch&date=2026-11-20` で、イベントダンジョンの戦闘を直接開けます。

**お知らせ・ホームのバナー**: イベントとガチャが始まると、お知らせが自動で1件増え（30日間残る）、ホームのバナーにも自動で入ります。

**ずらす**: サービス開始日が決まったら、`schedule.ts` の日付を、いっせいにずらしてください（季節のイベントは、実際の季節に合わせたほうが自然です）。

## 7. 未決定・これから

- 開始日と、イベントの細かい数字（通貨の量、交換所の値段、累計報酬の段階）は、仮です。実際に遊んで、調整してください。

- 日付は、端末の時計（日本時間のつもり）で動きます。サーバーを用意したら、サーバーの時刻に合わせます。
