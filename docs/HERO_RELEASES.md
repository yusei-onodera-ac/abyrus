# 新キャラの登場予定（先に作った30人）

★6 を10人、★5 を20人、**絵・声・スキル・セリフまで先に作って**あります。月に2人ずつ、**毎月1日と16日の0時（日本時間）**に1人ずつ、
ゲームに登場します（2026年12月〜2028年2月、15か月）。登場の前は、ゲームの中に「いない」ことになります（ガチャにも、図鑑にも出ません）。
絵・声のファイルは、はじめからアプリに入っています（登場日にアプリの更新は要りません）。

3か月で6人 = 1か月め ★5＋★5 / 2か月め ★5＋★6 / 3か月め ★5＋★6。これを5回（★5 x20、★6 x10）。職業は、となりどうしが同じにならないように散らしてあります。

## しくみ

- **登場の日付**は `src/game/data/heroRelease.ts` の表だけ。ここに書いていないキャラ（いまの161人）は、はじめから出ています。
  日付を変える・順を入れ替えるなら、その表だけを直します（`tools/tests/heroRelease.ts` が、月に2人・全員がちょうど1回・日付の形・職業の散らばりを確かめます）。
- **ゲームの中の「いる人」**は `HERO_ROSTER`、定義してある全員は `ALL_HEROES`（`src/game/data/heroes.ts`）。ガチャ・図鑑・起動時に読む小さい絵は、
  `HERO_ROSTER`（その日までに登場した人）だけを使います。起動のたびに、その日の時計で作り直します。**日付をまたいで遊び続けている人は、次に起動したときに反映**されます。
- ★5 は、登場の日から、いつものガチャの当たりに入ります。★6 は、いつものガチャには出ません（これまで通り、★6 の排出率がある「特設ガチャ」だけ）。登場した★6は、その特設ガチャの当たりに増えます。
- **図鑑の総数**も、登場に合わせて増えます（161 → 191）。全部そろえたごほうびの「全部」も、そのとき増えた総数です。
- 持っているキャラが、手元の時計が過去にずれても、壊れないようにしてあります（`getHeroDefinition` は未登場のキャラも見つける）。

## 先に見たいとき（開発）

開発サーバーと DEV のアドレスに `?date=2027-06-16` を付けると、その日のゲームになります（登場済みの人数も、その日の通り）。
`?date=2028-03-01` で、全員（191人）が出ます。`catalog.html` には、登場前のキャラも、「登場予定 日付」付きで載ります。

## 足していくとき（これから）

1. `tools/art/newCharacters2.mjs` の形で、キャラを書き足す（id・★・職業・名前・性別・絵の指示）。新しい束にするなら、別のファイルを作って `tools/art/manifest.mjs` と `tools/audio/manifest.mjs` に読ませる。
2. 絵: `node tools/art/generate.mjs --group chars3 --variants 2 --yes` → `python tools/art/process.py --compare` → 選んだ案を `tools/art/pick.json` → `python tools/art/process.py --install --group chars3` → `python tools/art/make_thumbs.py`（小さい絵）。
3. 声: `node tools/audio/extract.mjs` → `node tools/audio/generate.mjs --group voice --only <id>_1,<id>_2,<id>_3 --yes` → `python tools/audio/process.py --install --only ...`。
4. データ: `src/game/data/heroes.ts`（`ALL_HEROES`）、`skills.ts`（★5・★6は4つ）、`heroLines.ts`（セリフ3つ）に、同じ id で足す。
5. 登場日: `src/game/data/heroRelease.ts` に足す。`npm test`（`roster` が絵・声・スキル・セリフの有無を、全員分確かめます）。
