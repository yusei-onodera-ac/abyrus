# 公開前のチェックリスト

2026-11-18 作成。「細かいところを実装したら公開する」ための、やることの一覧です。
**誰が** は、決めたり用意したりするのが、あなた（運営）か、こちら（開発）か。**状態** は、この日付の時点で、コードやファイルを見て確かめたこと
（確かめていないものは「？」）。iOS のビルドの手順そのものは `docs/IOS_BUILD.md`。

## 3. アプリ本体（こちら。Mac と実機はあなたが用意）

| 項目 | 状態 |
|---|---|
| 実機のメモリと動き | **一度も測っていない。** 古い iPhone（RAM 3〜4GB）で、ホーム → 編成 → 詳細 → ガチャ → 戦闘 |
| アプリ内課金（StoreKit） | **作った** (iOS のアプリだけ: StoreKit 2 + サーバーでの署名つき取引の確認。ウェブ・開発ビルドは、今までどおり)。**Windows で作っただけで、実機・Xcode・サンドボックス・審査では、一度も通していない (未確認)**。Mac での手順・確認の項目・「復元」ボタンの判断材料は `docs/PAYMENTS.md` |
| 広告 | `AdSystem` は偽。本物の広告 SDK をつなぐ（つながないなら、広告の枠を消す） |
| アイコンと起動画面 | Capacitor の仮のまま。1024px のアイコンと起動画面の絵が要る（絵はあなた） |
| 音の自動再生 | WKWebView は、画面に触れる前の再生を止める。最初のタップのあとに鳴るか、実機で確かめる |
| `PrivacyInfo.xcprivacy`、App Privacy（集めるデータ） | ？ （集めているのは、端末ごとの匿名ID、ランキングと同盟のための名前と成績、チャット。**課金で、購入の取引 ID・商品・日時を、匿名ID と結びつけて Firestore に保存する**: 「購入」の申告が要るか確かめる。広告 SDK を入れると増える） |
| 暗号化の申告（輸出コンプライアンス） | 通信は HTTPS、データ引き継ぎで AES を使う予定。Info.plist の `ITSAppUsesNonExemptEncryption` と、Connect の質問に、同じ答えを書く |
| 通知 | 入れていない（入れるなら、許可の聞き方と、文面の多言語化も） |
| 細長い画面・ノッチ | FIT なので上下に黒帯。見た目を決めてから |
| バージョン番号 | `package.json` は 0.0.0、Xcode の MARKETING_VERSION は 1.0。公開前にそろえる |
| クラッシュの報告・分析 | 入っていない（Crashlytics などを入れるか決める。入れるなら App Privacy も書き足す） |
