# 同盟（アライアンス）設計書

2026-11-11。いまの「軍団」は、フレンドを集めたグループチャットでしかない。これを、**同盟**という遊びに作り替える。
画面上の呼び名は「同盟」。（コード上の `social.groups` は、古いセーブの互換のために残すが、画面では使わない。）

## 遊びの6本柱

1. **共闘ボス（レイド）** … 同盟のみんなで、1週間に1体の巨大ボスを削る。
2. **同盟の育成** … 寄付で同盟Lvを上げると、メンバー全員に恩恵がつく。
3. **同盟対抗戦** … 週ごとのシーズン。同盟どうしで、同盟ポイントを争う。
4. **助っ人と支援** … メンバーのキャラを借りて出撃する。素材の支援、救援要請。
5. **同盟ミッション** … みんなの行動（ステージ・ガチャ・寄付・ボス …）が足されて進む、毎日3件と毎週1件の目標。達成したら、貢献した人が、それぞれ報酬を受け取る。
6. **同盟研究** … 寄付でたまる同盟の資金で進める、戦闘・収入・成長の3系統。メンバー全員に、控えめな加算がつく。

入り方は2通り：**検索して申請（または、自由参加の同盟にそのまま入る）** と **フレンドを招待**。

## 全体の作り（サーバー込み）

```
画面 (scenes/Alliance*.ts)
   │  同盟の状態は、AllianceService だけを通して読み書きする
   ▼
AllianceService (alliance/AllianceService.ts)   ← プレイヤー個人の状態（セーブ）と、同盟の状態をつなぐ
   │
   ├─ OnlineAllianceBackend (Firestore)   … Firebase が設定されているとき
   └─ LocalAllianceBackend  (セーブ内)     … 設定がないとき。疑似メンバー（NPC）で、同じルールのまま遊べる
```

- 両方の Backend は、同じ `AllianceBackend` インターフェース（`alliance/AllianceBackend.ts`）を実装する。
  画面とゲームのルールは、どちらの Backend かを知らない。
- Firebase が未設定でも、ゲームは普通に動く（`LeaderboardSystem` と同じ流儀）。ローカルでは、疑似メンバーが
  時間とともに寄付・挑戦・ダメージを積み、ボスも対抗戦も、本物と同じ形で進む。
- 戦闘はクライアントで動く。サーバーは、ダメージの上限（1回の挑戦で出せる最大値）と、1日の回数を、ルールで縛る。
  完全な不正対策ではない（戦闘をサーバーで再現しない限り無理）。対策は、`docs/ALLIANCE_SERVER.md` に書く。

## 同盟

| 項目 | 内容 |
|---|---|
| 名前 | 2〜10文字 |
| 紋章 | 紋章 0〜11（絵はコードで描く。色と形の組み合わせ） |
| 説明 | 最大60文字 |
| 人数 | 最大30人（同盟Lvで増える：Lv1=20, Lv5=25, Lv10=30） |
| 参加方式 | `open`（自由参加）/ `approval`（承認制）/ `invite`（招待のみ） |
| 参加条件 | プレイヤーLv の下限（0〜50） |
| 役職 | `leader`（1人）/ `officer`（最大3人）/ `member` |
| 作成 | 魔晶石 300個。1人1つの同盟にしか入れない。 |

役職の権限：
- leader: すべて（設定変更、役職の任命、除名、解散、リーダーの譲渡）
- officer: 申請の承認・却下、メンバーの除名（officer と leader 以外）、招待
- member: 寄付、ボスへの挑戦、助っ人の設定、チャット
- 抜ける：leader は、他のメンバーがいればリーダーを譲ってから抜ける。1人だけなら、抜けると解散。
- 7日間まったくログインしていない leader は、次の officer（いなければ貢献が最大のメンバー）に、自動で譲られる。
- 抜けてから24時間は、別の同盟に入れない（出入りでの悪用を防ぐ）。

## 育成：寄付と同盟Lv

- 寄付の種類（1日の上限は、メンバーごと）：

  | 寄付 | 1回 | 同盟EXP | 個人の貢献 | 1日の上限 |
  |---|---|---|---|---|
  | ゴールド | 現在の「放置報酬1時間分」 | +100 | +10 | 5回 |
  | 素材（木・鉄・石の合計） | 100個 | +120 | +12 | 5回 |
  | 魔晶石 | 10個 | +300 | +30 | 3回 |

- 貢献は、個人の「同盟コイン」にもなる（貢献1 = 1コイン）。同盟ショップで使う。
- 同盟EXPがたまると、同盟Lvが上がる。必要EXP = `3000 * 1.6^(Lv-1)`（Lv10まで。合計 約34万）。1日に、メンバー1人が積める最大は 2,000（ゴールド5回・素材5回・魔晶石3回）。20人のうち6割が1,500ずつ積む同盟で、およそ19日でLv10。
- 同盟Lvごとの恩恵（メンバー全員）：

  | 同盟Lv | 放置ゴールド | 経験値素材（ドロップ） | スタミナ上限 | 挑戦回数 | 人数 |
  |---|---|---|---|---|---|
  | 1 | +0% | +0% | +0 | 3回/日 | 20 |
  | 2 | +2% | | | | |
  | 3 | +4% | +3% | | | |
  | 4 | +6% | +3% | +5 | | |
  | 5 | +8% | +6% | +5 | 4回/日 | 25 |
  | 6 | +10% | +6% | +10 | | |
  | 7 | +12% | +9% | +10 | | |
  | 8 | +14% | +9% | +15 | 5回/日 | |
  | 9 | +16% | +12% | +15 | | |
  | 10 | +20% | +15% | +20 | 5回/日 | 30 |

  （数字は仮のバランス。実装では `data/alliance.ts` の表だけを直せばよい。）
- 同盟ショップ：同盟コインで、フェーズ素材、装備強化素材、経験値素材、魔晶石（週1回）を買える。

## 共闘ボス（レイド）

- 週ごとに、ボスが1体出る（月曜0:00に切り替わる）。ボスは、同盟Lvに合わせた強さの、HPがとても大きい敵。
  ボスの一覧は `data/alliance.ts` の表（全5体を、順番に回す）。
- 各メンバーは、1日に **挑戦回数**（同盟Lvで3〜5回）だけ、ボスに挑める。挑戦は、スタミナを使わない。
- 1回の挑戦 = 60秒の戦闘。自分のパーティ（＋助っ人1体）で、ボスを殴り、**与えたダメージ**がその回の成績になる。
  ボスは、HPが減らない特別な敵として戦い、60秒で打ち切る（途中で全滅しても、そこまでのダメージは入る）。
- 与えたダメージは、同盟のボスHPから引かれる。HPが0になれば撃破。
- 撃破したときの報酬：**1回でもダメージを与えたメンバー全員**に、基本報酬（魔晶石・フェーズ素材・同盟コイン）。
  与えたダメージの上位3人には、追加報酬。撃破できなくても、週の終わりに、与えたダメージに応じた参加報酬が出る。
- 挑戦回数は、毎日4:00に回復する（ローカル時刻ではなく、サーバー時刻で数える）。
- 1回の挑戦で出せるダメージには、上限を置く（`maxDamagePerAttempt`：パーティの総合力 × 係数）。これを超える申告は、サーバーが切り捨てる。係数は 15（実際に出るダメージは、auto で、総合力の約4〜6.5倍。戦闘を画面なしで動かして測った）。
- ボスのHP = メンバーの総合力の合計 × 14 × 1日の挑戦回数 × （同盟Lv・ボスの順で少しずつ重く）。「全員が挑戦回数の4割を使えば倒せる」重さ。

## 同盟対抗戦

- 週ごとのシーズン（月曜0:00〜日曜23:59）。同盟は、強さが近い同盟ごとの「リーグ」に自動で振り分けられる
  （ブロンズ・シルバー・ゴールド・プラチナ・ダイヤ）。1リーグ最大20同盟。
- **同盟ポイント**の入り方：
  - ボスへのダメージ：与えたダメージ10,000につき1ポイント（※実装では、対数に近いスケールにして、桁があふれないようにする）
  - 寄付：貢献1 = 1ポイント
  - メインステージの初クリア：1ステージ = 20ポイント
  - 助っ人を貸した：1回 = 5ポイント（借りた人が出撃したとき）
- 週の終わりに、リーグ内の順位で、メンバー全員に報酬（魔晶石・同盟コイン・称号の紋章）。
  上位3同盟はリーグが上がり、下位3同盟は下がる。
- 画面には、リーグ表（順位・同盟名・ポイント）、自分の同盟のポイントの内訳、残り時間が出る。

## 助っ人と支援

- **助っ人**：各メンバーは、自分のキャラを1体、「助っ人」に登録できる（Lv・フェーズ・スキル・装備つきのスナップショット）。
- 出撃前の編成画面で、同盟メンバーの助っ人を1体借りられる（1回の戦闘で1体、パーティの6人目として加わる）。
  借りられるのは、メインステージ、曜日ダンジョン、共闘ボス。無限モードは対象外。
- 借りると、貸した側に、**同盟コイン 5**と対抗戦ポイントが入る。同じ人の助っ人を、1日に何度借りても、貸した側の報酬は1日に3回まで。
- **支援**：メンバーに、スタミナ回復（10）を贈る。1日に5人まで。受け取った側は、1日に受け取れる上限は10個まで。
- **救援要請**：村の襲撃が来ているとき、または共闘ボスの残り時間が短いときに、同盟チャットに要請を出せる。
  メンバーがタップすると、貢献が少し入る（要請した人には、助けてくれた人の数が出る）。

## 同盟ミッション

2026-11-24 追加。「みんなで、ちょっとずつ遊ぶ」理由を、毎日つくる。数字と中身は `data/allianceMissions.ts` の表だけ。決まり（目標の選び方・数え方・受け取り）は、`alliance/missionLogic.ts`（Local も Online も同じものを使う）。

- **毎日 3件**（日替わりは 4:00）と、**毎週 1件**（月曜 0:00）。毎日は、6つの中から3つ（行動はかぶらない）。毎週は、5つが順番に回る。
- メンバー全員の行動が、同盟の合計に足される。画面には、同盟の進み（棒）、**自分の貢献と順位**、貢献の**上位3人**が出る。
- **数える行動**（8つ）。1人が1期間に足せる量には、上限がある（ふつうの遊びでは届かない大きさ。改造した申告の頭打ち）。週の上限は、1日の7倍。

  | 行動 | 数えるもの | 1日の上限 |
  |---|---|---|
  | stage | クエストのクリア（掃討の回数も） | 300 |
  | gacha | ガチャを引いた数 | 300 |
  | donate | 同盟への寄付の回数 | 13 |
  | raid | 共闘ボスへの挑戦 | 5 |
  | stamina | 使ったスタミナ | 1,000 |
  | idle | 放置報酬の受け取り | 10 |
  | enhance | キャラ・装備の強化 | 200 |
  | helper | 助っ人を借りて出撃 | 20 |

- **どこで数えるか**：個人のミッション（`recordMission`）が数えている行動（クエスト・ガチャ・スタミナ・放置報酬・強化）は、同じ場所で、同盟ミッション用にも数える。寄付・共闘ボス・助っ人は、`AllianceService` が数える。数は、いったん**セーブに貯めて**（`alliance.missionPending`）、次に `AllianceService` が呼ばれたとき（同盟の画面を開いたとき）に、まとめて送る。メインステージの初クリアのポイント（`pendingStagePoints`）と、同じやり方。送れなかった分は、次に回る。
- **目標の数** ＝ max(下限, 切り上げ(1人あたり × 期間の初めのメンバー数))。きりのよい数に丸める。期間の初めに決まって、途中で変わらない（途中で入った人は、目標を動かさない）。1人の同盟でも、下限で遊べる。「同盟の4割ほどが、ふつうに遊んだ日」に、ちょうど届く量にした。

  | 毎日 | 行動 | 1人あたり | 下限 | 受け取りに必要な貢献 | 報酬 |
  |---|---|---|---|---|---|
  | クエストをクリアしよう | stage | 6 | 10 | 3 | 同盟コイン 25・経験値素材(中) ×3 |
  | ガチャを引こう | gacha | 2 | 3 | 1 | 同盟コイン 25・魔晶石 10 |
  | 同盟に寄付しよう | donate | 1.5 | 3 | 1 | 同盟コイン 25・ゴールド1時間分 |
  | スタミナを使おう | stamina | 80 | 100 | 20 | 同盟コイン 25・装備強化素材 ×60 |
  | キャラや装備を強化しよう | enhance | 3 | 3 | 1 | 同盟コイン 25・経験値素材(小) ×30 |
  | 放置報酬を受け取ろう | idle | 0.7 | 2 | 1 | 同盟コイン 25・魔晶石 10 |

  | 毎週（報酬は全部 同盟コイン 100・魔晶石 60・フェーズ素材 1） | 行動 | 1人あたり | 下限 | 受け取りに必要な貢献 |
  |---|---|---|---|---|
  | クエストをみんなでクリア | stage | 40 | 60 | 10 |
  | みんなで寄付を積み上げる | donate | 10 | 15 | 3 |
  | 共闘ボスに全員で挑む | raid | 6 | 4 | 1 |
  | みんなでガチャを引く | gacha | 12 | 15 | 3 |
  | みんなでスタミナを使う | stamina | 500 | 600 | 100 |

- **受け取り**：同盟が目標に届いていて、自分の貢献が「受け取りに必要な貢献」以上のとき、**1人1回**。報酬は、必ず `showRewardModal` で見せて、「確認」で閉じる。同盟コインは、バックエンドが足す（ほかの報酬と同じ）。期間を過ぎると受け取れなくなる（持ち越さない。画面に、残り時間が出る）。
- 報酬の同盟コインは、1回の受け取りで 100 まで（Online のルールの、1回の書き込みの上限に合わせた）。毎日のぶんは、3件そろって 同盟コイン 75・魔晶石は多くて 20（あとは、素材など）。寄付で1日に貯められる同盟コイン（最大 200）の、4割ほどで、ショップの値段（フェーズ素材 150 コイン）から見て、おまけの範囲。
- **ローカル（疑似メンバー）**：疑似メンバーは、1日の数の目安（`MISSION_SIM_PER_DAY`、活発さ 1 のとき）を、時間帯の重みで割って、1時間ごとに足す（寄付と共闘ボスは、疑似メンバーの本当の寄付・挑戦が数える）。疑似メンバーだけで、目標の **8割前後**（試験では平均 80%）まで進むので、自分が足すと、ちょうど届く。同盟に入った時点で、途中までは進んでいる。

## 同盟研究

2026-11-24 追加。同盟Lv の恩恵（Lv ごとの自動の加算）とは別に、**同盟が自分たちで選んで伸ばす**加算。数字と中身は `data/allianceResearch.ts` の表だけ。

- **資金**：寄付1回につき、その寄付の同盟EXPと同じ数だけ貯まる（ゴールド +100 / 素材 +120 / 魔晶石 +300）。同盟EXP（同盟Lv）とは別の財布。1日に、メンバー1人が積める最大は 2,000。活発な同盟（20人のうち6割が 1,500ずつ）で、1日 18,000。
- **3系統 × 5段**。値段と、必要な同盟Lv は、段で決まる（どの系統も同じ。ルールを小さく保つため）。効果は、その段までの合計。

  | 段 | 値段（資金） | 必要な同盟Lv | 戦闘 | 収入 | 成長 |
  |---|---|---|---|---|---|
  | 1 | 15,000 | 2 | +1% | +2% | +2% |
  | 2 | 30,000 | 3 | +2% | +4% | +4% |
  | 3 | 60,000 | 5 | +3% | +6% | +6% |
  | 4 | 110,000 | 7 | +4% | +8% | +8% |
  | 5 | 180,000 | 9 | +5% | +10% | +10% |

  1系統を最後まで進めるのに、資金 395,000（活発な同盟で、およそ3週間）。3系統そろえて 1,185,000（およそ2か月）。1段目は、1日で届く。
- **だれが**：同盟長と副長が、系統を選んで、1段ずつ進める（すぐに終わる。時間はかからない）。資金を使うので、確認のダイアログを出す。メンバーは、画面を見られるだけ。
- **効果の足し先**（どれも、同盟に入っている間だけ。抜けると消える）。いまの同盟Lv の恩恵に、**足し算**で乗る:

  | 系統 | 効果 | 足し先 |
  |---|---|---|
  | 戦闘 | 味方全員の攻撃力と HP（それぞれ） | `BattleSystem.createPlayerUnit` の倍率 `statMul`（`BattleScene` と共闘ボス戦。助っ人にもかかる）。**無限モードにはかけない**（ランキングを、同盟に入っているかどうかで変えないため） |
  | 収入 | 放置ゴールド | `allianceIdleGoldBonus`（`IdleSystem.perHour`） |
  | 成長 | 経験値素材のドロップ | `allianceExpDropBonus`（`StageRewardSystem.grant`） |

  最大で、放置ゴールド +30%（Lv10 の +20% と、研究の +10%）、経験値素材 +25%（+15% と +10%）、戦闘 +5%。控えめにしたのは、同盟Lv の恩恵と、キャラの育成を、置き換えないため。戦闘の +5% は、総合力の表示には入らない（戦ったときだけ）。共闘ボスのダメージの上限（総合力 × 15）は、実際に出るダメージ（4〜6.5倍）の2倍以上あるので、+5% で上限に当たることはない。
- **セーブ**：入っている同盟の、系統ごとの段を `alliance.research` に写す（同盟の画面を開いたとき・研究したとき）。効果の計算は、同盟Lv と同じく、このセーブの値を見る。

## チャット

同盟には、メンバー全員のチャットが1つある（いまのグループチャットは、ここに引っ越す）。
システムメッセージ（寄付、ボス撃破、リーグの昇降、加入・脱退）が、同じ流れに入る。絵文字は、これまでどおり、ゲーム内のものだけ。

## 画面

- ホームの「メッセージ」と下の「フレンド」タブの近くに、**同盟**の入口。同盟がなければ「同盟を探す」を、あれば同盟ホームを開く。
- **同盟ホーム**：紋章・名前・Lv・EXPバー・人数・今週のボスカード・**ミッションカード**・**研究カード**・対抗戦カード・助っ人カード・メニュー
  （メンバー / 寄付 / ショップ / チャット / 設定）。ミッションカードの赤丸は、受け取れる報酬があるとき。研究カードの赤丸は、同盟長・副長が、いま研究できる段があるとき。
- 同盟を探す：一覧（名前・Lv・人数・参加方式・条件）、検索（名前）、おすすめ、作成、招待されている同盟。
- メンバー一覧：役職・Lv・総合力・今週の貢献・最終ログイン。タップで、プロフィール、役職変更、除名、フレンド申請。
- 共闘ボス画面：ボスの絵・HPバー・残り時間・自分の挑戦回数・与えたダメージ・上位ランキング、挑戦ボタン。
- 対抗戦画面：リーグ表、ポイントの内訳、報酬の一覧。
- ミッション画面：今日の3件と今週の1件。それぞれ、進みの棒・自分の貢献と順位・上位3人・報酬・「受け取る」ボタン（受け取り済み・貢献不足・進行中も、ここで見える）。受け取ると、報酬ポップアップ（「確認」で閉じる）。
- 研究画面：同盟の資金、3系統のカード（段・いまの効果・次の段の効果と値段・必要な同盟Lv・「研究する」）。研究する前に、確認のダイアログ。

## ローカル（疑似メンバー）の動き

Firebase が無いとき、`LocalAllianceBackend` は、同盟ごとに疑似メンバーを持つ（名前・Lv・総合力は、乱数のシードから固定で作る）。
時計を見て、疑似メンバーが、寄付・挑戦・ダメージを自動で積む（1時間ごとに、確率で）。ボスのHPは、プレイヤーと疑似メンバーの
合計で減り、報酬の受け取りも、本物と同じ手順で出る。他の同盟（対抗戦の相手、検索の一覧）も、シード付きの疑似同盟として並ぶ。
疑似メンバーのチャットは、数時間に1行、定型文が入る。
