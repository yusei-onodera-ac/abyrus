# 同盟（アライアンス）設計書

2026-11-11。いまの「軍団」は、フレンドを集めたグループチャットでしかない。これを、**同盟**という遊びに作り替える。
画面上の呼び名は「同盟」。（コード上の `social.groups` は、古いセーブの互換のために残すが、画面では使わない。）

## 遊びの4本柱

1. **共闘ボス（レイド）** … 同盟のみんなで、1週間に1体の巨大ボスを削る。
2. **同盟の育成** … 寄付で同盟Lvを上げると、メンバー全員に恩恵がつく。
3. **同盟対抗戦** … 週ごとのシーズン。同盟どうしで、同盟ポイントを争う。
4. **助っ人と支援** … メンバーのキャラを借りて出撃する。素材の支援、救援要請。

入り方は2通り：**検索して申請（または、自由参加の同盟にそのまま入る）** と **フレンドを招待**。

## 全体の作り（サーバー込み）

```
画面 (scenes/Alliance*.ts)
   │  同盟の状態は、AllianceService だけを通して読み書きする
   ▼
AllianceService (alliance/AllianceService.ts)   ← プレイヤー個人の状態（セーブ）と、同盟の状態をつなぐ
   │
   ├─ OnlineAllianceBackend (Firestore)   … Firebase が設定されているとき
   └─ LocalAllianceBackend  (セーブ内)     … 設定がないとき。疑似メンバー（NPC）で、同じルールのまま遊べる
```

- 両方の Backend は、同じ `AllianceBackend` インターフェース（`alliance/AllianceBackend.ts`）を実装する。
  画面とゲームのルールは、どちらの Backend かを知らない。
- Firebase が未設定でも、ゲームは普通に動く（`LeaderboardSystem` と同じ流儀）。ローカルでは、疑似メンバーが
  時間とともに寄付・挑戦・ダメージを積み、ボスも対抗戦も、本物と同じ形で進む。
- 戦闘はクライアントで動く。サーバーは、ダメージの上限（1回の挑戦で出せる最大値）と、1日の回数を、ルールで縛る。
  完全な不正対策ではない（戦闘をサーバーで再現しない限り無理）。対策は、`docs/ALLIANCE_SERVER.md` に書く。

## 同盟

| 項目 | 内容 |
|---|---|
| 名前 | 2〜10文字 |
| 紋章 | 紋章 0〜11（絵はコードで描く。色と形の組み合わせ） |
| 説明 | 最大60文字 |
| 人数 | 最大30人（同盟Lvで増える：Lv1=20, Lv5=25, Lv10=30） |
| 参加方式 | `open`（自由参加）/ `approval`（承認制）/ `invite`（招待のみ） |
| 参加条件 | プレイヤーLv の下限（0〜50） |
| 役職 | `leader`（1人）/ `officer`（最大3人）/ `member` |
| 作成 | 魔晶石 300個。1人1つの同盟にしか入れない。 |

役職の権限：
- leader: すべて（設定変更、役職の任命、除名、解散、リーダーの譲渡）
- officer: 申請の承認・却下、メンバーの除名（officer と leader 以外）、招待
- member: 寄付、ボスへの挑戦、助っ人の設定、チャット
- 抜ける：leader は、他のメンバーがいればリーダーを譲ってから抜ける。1人だけなら、抜けると解散。
- 7日間まったくログインしていない leader は、次の officer（いなければ貢献が最大のメンバー）に、自動で譲られる。
- 抜けてから24時間は、別の同盟に入れない（出入りでの悪用を防ぐ）。

## 育成：寄付と同盟Lv

- 寄付の種類（1日の上限は、メンバーごと）：

  | 寄付 | 1回 | 同盟EXP | 個人の貢献 | 1日の上限 |
  |---|---|---|---|---|
  | ゴールド | 現在の「放置報酬1時間分」 | +100 | +10 | 5回 |
  | 素材（木・鉄・石の合計） | 100個 | +120 | +12 | 5回 |
  | 魔晶石 | 10個 | +300 | +30 | 3回 |

- 貢献は、個人の「同盟コイン」にもなる（貢献1 = 1コイン）。同盟ショップで使う。
- 同盟EXPがたまると、同盟Lvが上がる。必要EXP = `1000 * 1.6^(Lv-1)`（Lv10まで）。
- 同盟Lvごとの恩恵（メンバー全員）：

  | 同盟Lv | 放置ゴールド | 経験値素材（ドロップ） | スタミナ上限 | 挑戦回数 | 人数 |
  |---|---|---|---|---|---|
  | 1 | +0% | +0% | +0 | 3回/日 | 20 |
  | 2 | +2% | | | | |
  | 3 | +4% | +3% | | | |
  | 4 | +6% | +3% | +5 | | |
  | 5 | +8% | +6% | +5 | 4回/日 | 25 |
  | 6 | +10% | +6% | +10 | | |
  | 7 | +12% | +9% | +10 | | |
  | 8 | +14% | +9% | +15 | 5回/日 | |
  | 9 | +16% | +12% | +15 | | |
  | 10 | +20% | +15% | +20 | 5回/日 | 30 |

  （数字は仮のバランス。実装では `data/alliance.ts` の表だけを直せばよい。）
- 同盟ショップ：同盟コインで、フェーズ素材、装備強化素材、経験値素材、魔晶石（週1回）を買える。

## 共闘ボス（レイド）

- 週ごとに、ボスが1体出る（月曜0:00に切り替わる）。ボスは、同盟Lvに合わせた強さの、HPがとても大きい敵。
  ボスの一覧は `data/alliance.ts` の表（全5体を、順番に回す）。
- 各メンバーは、1日に **挑戦回数**（同盟Lvで3〜5回）だけ、ボスに挑める。挑戦は、スタミナを使わない。
- 1回の挑戦 = 60秒の戦闘。自分のパーティ（＋助っ人1体）で、ボスを殴り、**与えたダメージ**がその回の成績になる。
  ボスは、HPが減らない特別な敵として戦い、60秒で打ち切る（途中で全滅しても、そこまでのダメージは入る）。
- 与えたダメージは、同盟のボスHPから引かれる。HPが0になれば撃破。
- 撃破したときの報酬：**1回でもダメージを与えたメンバー全員**に、基本報酬（魔晶石・フェーズ素材・同盟コイン）。
  与えたダメージの上位3人には、追加報酬。撃破できなくても、週の終わりに、与えたダメージに応じた参加報酬が出る。
- 挑戦回数は、毎日4:00に回復する（ローカル時刻ではなく、サーバー時刻で数える）。
- 1回の挑戦で出せるダメージには、上限を置く（`maxDamagePerAttempt`：パーティの総合力 × 係数）。これを超える申告は、サーバーが切り捨てる。

## 同盟対抗戦

- 週ごとのシーズン（月曜0:00〜日曜23:59）。同盟は、強さが近い同盟ごとの「リーグ」に自動で振り分けられる
  （ブロンズ・シルバー・ゴールド・プラチナ・ダイヤ）。1リーグ最大20同盟。
- **同盟ポイント**の入り方：
  - ボスへのダメージ：与えたダメージ10,000につき1ポイント（※実装では、対数に近いスケールにして、桁があふれないようにする）
  - 寄付：貢献1 = 1ポイント
  - メインステージの初クリア：1ステージ = 20ポイント
  - 助っ人を貸した：1回 = 5ポイント（借りた人が出撃したとき）
- 週の終わりに、リーグ内の順位で、メンバー全員に報酬（魔晶石・同盟コイン・称号の紋章）。
  上位3同盟はリーグが上がり、下位3同盟は下がる。
- 画面には、リーグ表（順位・同盟名・ポイント）、自分の同盟のポイントの内訳、残り時間が出る。

## 助っ人と支援

- **助っ人**：各メンバーは、自分のキャラを1体、「助っ人」に登録できる（Lv・フェーズ・スキル・装備つきのスナップショット）。
- 出撃前の編成画面で、同盟メンバーの助っ人を1体借りられる（1回の戦闘で1体、パーティの6人目として加わる）。
  借りられるのは、メインステージ、曜日ダンジョン、共闘ボス。無限モードは対象外。
- 借りると、貸した側に、**同盟コイン 5**と対抗戦ポイントが入る。同じ人の助っ人を、1日に何度借りても、貸した側の報酬は1日に3回まで。
- **支援**：メンバーに、スタミナ回復（10）を贈る。1日に5人まで。受け取った側は、1日に受け取れる上限は10個まで。
- **救援要請**：村の襲撃が来ているとき、または共闘ボスの残り時間が短いときに、同盟チャットに要請を出せる。
  メンバーがタップすると、貢献が少し入る（要請した人には、助けてくれた人の数が出る）。

## チャット

同盟には、メンバー全員のチャットが1つある（いまのグループチャットは、ここに引っ越す）。
システムメッセージ（寄付、ボス撃破、リーグの昇降、加入・脱退）が、同じ流れに入る。絵文字は、これまでどおり、ゲーム内のものだけ。

## 画面

- ホームの「メッセージ」と下の「フレンド」タブの近くに、**同盟**の入口。同盟がなければ「同盟を探す」を、あれば同盟ホームを開く。
- **同盟ホーム**：紋章・名前・Lv・EXPバー・人数・今週のボスカード・対抗戦カード・助っ人カード・メニュー
  （メンバー / 寄付 / ショップ / チャット / 設定）。
- 同盟を探す：一覧（名前・Lv・人数・参加方式・条件）、検索（名前）、おすすめ、作成、招待されている同盟。
- メンバー一覧：役職・Lv・総合力・今週の貢献・最終ログイン。タップで、プロフィール、役職変更、除名、フレンド申請。
- 共闘ボス画面：ボスの絵・HPバー・残り時間・自分の挑戦回数・与えたダメージ・上位ランキング、挑戦ボタン。
- 対抗戦画面：リーグ表、ポイントの内訳、報酬の一覧。

## ローカル（疑似メンバー）の動き

Firebase が無いとき、`LocalAllianceBackend` は、同盟ごとに疑似メンバーを持つ（名前・Lv・総合力は、乱数のシードから固定で作る）。
時計を見て、疑似メンバーが、寄付・挑戦・ダメージを自動で積む（1時間ごとに、確率で）。ボスのHPは、プレイヤーと疑似メンバーの
合計で減り、報酬の受け取りも、本物と同じ手順で出る。他の同盟（対抗戦の相手、検索の一覧）も、シード付きの疑似同盟として並ぶ。
疑似メンバーのチャットは、数時間に1行、定型文が入る。
